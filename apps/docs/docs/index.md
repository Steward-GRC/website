# Steward documentation

Steward is an open-source system for managing policies and procedures. People write them, submit them for approval, approvers approve or reject them, and published documents are read, versioned and printed.

The documentation has three parts.

- [User guide](./user/index.md): writing, the editor, approvals, appendices, definitions, references and contacts, reading and history.
- [Admin guide](./admin/index.md): categories, templates, workflows and who can do what.
- [Demo](./demo/index.md): how to try the Steward demo, what is real and what is simulated, the test people and the limits of the demo.
