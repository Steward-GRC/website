# Search and the command bar

The **command bar** is one box that searches Steward and runs commands. It is in both apps, on every page after you sign in. Use it to jump to a document, to start a new one, or to run an action for the page you are on, without reaching for the mouse.

## Open it

Any of these opens the command bar:

| Do this                                              | What happens                                                                                                   |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Press **Cmd+K** (Mac) or **Ctrl+K** (Windows, Linux) | Opens it on any page, even if the search field in the header is hidden on a narrow screen.                     |
| Click the **Search** field in the header             | Opens it. Anything you had typed in the field comes with you.                                                  |
| Start typing in the **Search** field                 | Opens it with your first letters already in the box.                                                           |
| Press **Shift+C**                                    | Opens it with **New** typed, so only the create actions show. It does nothing while you are typing in a field. |

Press **Esc** to close it. The shortcuts that show beside an action, such as **H** for **History & approvals**, work from the page without opening the command bar; press **?** on any page for the full list.

## With nothing typed

<Screenshot slot="search-1" alt="The command bar open with nothing typed, showing Actions, Create and Recent" />

1. The **Search** field in the header, with its **Cmd+K** key hint. Click it, or press the shortcut, to open the command bar.
2. The **Search Steward** box. Type here; **Esc** closes the bar.
3. **Actions**: what you can do on the page you are on, with the key for each.
4. **Create**: **New policy**, **New procedure** and **New draft from a template**.
5. **Recent**: documents you opened from the command bar before.

Use the up and down arrow keys to move through the list and **Enter** to choose. Press **Cmd+Enter** (**Ctrl+Enter**) to open the choice in a new tab.

- **Actions** change with the page. On a document you may see **Print / Export** and **History & approvals**. On the Library you may see **Open the inbox**. **Show the keyboard shortcuts** is always there.
- **Create** lists only what you may create. Someone who cannot write in any category sees no **Create** group.
- **Recent** holds the last five documents you opened from the command bar. It is kept in your browser only, so another browser or device starts with an empty list.

## Search for a document

Type words from a title, a document number or a category. The results fill in as you type, grouped, with the part that matches underlined.

<Screenshot slot="search-2" alt="The command bar after typing supplier, with Policies and Procedures results" />

1. What you typed. Clear it with the **x** at the right.
2. **Policies** that match, with the document number and category under each title.
3. **Procedures** that match.
4. **See all results for ...**, which opens the full Search page.

In the staff app the groups are **Policies**, **Procedures** and **Categories**. Choose a document to open it, or a category to go to it. If nothing matches, the bar says **Nothing matches** with your words; **See all results** is still there if you want to try the full page.

Words that name an action narrow the **Actions** and **Create** groups too. Type `proc` and **New procedure** is the only create action left.

## Start something new

Press **Shift+C**, or type **New**, to see only the things you can create.

<Screenshot slot="search-3" alt="The command bar opened with Shift+C, listing the create actions" />

1. **New** is typed for you, selected, so typing replaces it. Only create actions match.
2. The **Create** group: what Bob may create.
3. **New policy**, the first action. Press **Enter** to start it.

Choosing an action opens the same page the buttons in the Library do. See [Policies and procedures](./policies-and-procedures.md).

## In the admin app

The admin app has the same command bar, with the same keys. It searches more kinds of thing, and its actions are the admin tasks.

<Screenshot slot="search-4" alt="The command bar in the admin app on a published document, with an Admin group" />

1. The **Search Steward** box.
2. **Actions**: the everyday actions for this page.
3. **Admin**: the admin-only tasks for this page, each marked **Admin**.
4. **Create**: what an admin may create, starting with **New category**. Scroll the list for the rest.

- Search finds **Policies**, **Categories**, **Groups** and **Templates**. A template shows its code, such as `TPL-001`.
- On a published document the **Admin** group lists **Export PDF**, **Magic link**, **Change author**, **Move to section**, **Retire** and **Delete**. Each is also in the document's **Admin actions** menu. Type `admin` to show the whole group.
- **Create** offers **New category**, **New group**, **New template**, **New workflow**, **New organisation** and **New magic link**.

Choosing an admin action opens its dialog, which asks you to confirm before anything changes.
