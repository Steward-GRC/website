# User guide

Steward is an open-source system for managing policies and procedures. People write them, submit them for approval, approvers approve or reject them, and published documents are read, versioned and printed. You do not need to know Steward first.

1. The left navigation: Library, Templates, Approvals and the other staff pages.
2. The "My work" page, which lists what is waiting on the signed-in person.

## Two apps

| App       | Address                               | Who it is for                                                   |
| --------- | ------------------------------------- | --------------------------------------------------------------- |
| Staff app | the Steward address                   | Everyone: library, drafting, approvals, reading                 |
| Admin app | the same address followed by `/admin` | Admins only: categories, templates, workflows, users, libraries |

The apps are linked. The staff app has an **Admin** link in its header for people who may use it. Someone without admin rights who opens `/admin` sees "Admins only".

## Roles

- An **author** writes drafts and submits them for approval.
- An **approver** approves or rejects what is submitted, and comments on it.
- A **reader** reads published documents and acknowledges policies.

Everyone is also a reader. Which categories a person may write in or approve for is set per category; see [Admin](../admin/index.md#who-can-do-what).
